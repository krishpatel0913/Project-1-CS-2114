# TimeFit
TimeFit is a text-based app that handles user input in order to create a personalized gym schedule and routine(s) for a user based on their chosen goal and availability.

# Instructions
To run TimeFit, please download the zip folder, unzip it, and run TimeFit as a Java Application.
